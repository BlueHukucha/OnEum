# 온음 v0.4 — Mobile First PWA

## 기능
- 모바일 3단계 화면 (음원 선택 → 녹음 → 결과)
- 사용자가 보유한 MP3/WAV 등 로컬 오디오 재생
- 녹음 시작 시 음원을 처음부터 재생 (정밀 동기화는 아님)
- 마이크 단일 음정 추정과 음정 그래프
- 결과 그래프 간단히 보기(5포인트 중앙값) / 자세히 보기(원본)
- 녹음 다운로드, 음정 JSON 데이터 다운로드
- 서버·로그인·유료 API 없음

## 테스트 / 배포
ZIP 압축을 풀어 모든 파일을 GitHub Pages 저장소의 최상위에 업로드하세요.
Settings → Pages → Deploy from a branch → main / root.
HTTPS 사이트에서 Safari/Chrome 마이크 권한을 허용하세요.
로컬 테스트는 `python3 -m http.server 8000` 실행 후 http://localhost:8000 을 여세요.

## 한계
원곡 멜로디 분석, 코드 인식, 원곡과 녹음 비교 및 채점은 아직 없습니다.
음정 추정은 소음, 옥타브 오류, 음역 및 비브라토에 영향을 받습니다.
브라우저 및 휴대폰 기종별 마이크/재생 동작은 실기기 검증이 필요합니다.
녹음은 다운로드하지 않으면 탭 종료 후 보존되지 않습니다.
저작권 있는 음원은 본인이 이용 권한을 가진 범위에서 사용하세요.

- 녹음 일시정지/재개: 원곡 재생도 함께 멈추며 타임라인에서 일시정지 시간 제외
- 파일 선택기 MP3/M4A/WAV/MP4 확장 (기기/코덱에 따라 재생 불가할 수 있음)
